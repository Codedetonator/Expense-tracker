# ExpenseTracker

An Android application designed to help users manage their daily expenses and personal finances.

## Features

- Track daily expenses
- Dashboard with spending overview
- Weekly expense chart
- Wallet and cash denomination management
- Lending and repayment tracking
- Trip expense management
- Wishlist management
- Home screen money widget

## Tech Stack

- Kotlin
- Android SDK
- XML
- Room Database
- Gradle

## Project Structure

- `data/` - Database, entities, DAOs and repository
- `ui/` - Screens, ViewModels and adapters
- `util/` - Utility classes
- `widget/` - Home screen widget

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Wait for Gradle sync to finish.
4. Run the application on an emulator or Android device.
